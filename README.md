> **corridance** (n.) the mirrored sidestep two strangers do in a hallway, each dodging the same way twice.

*Corridance* — corridor + dance — names the little mirrored shuffle everyone has done and no one had a word for: you step left, they step right, you both step the same way again, laughing awkwardly, before finally passing each other.
